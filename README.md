> Todas em **português**, bem documentadas, não-bloqueantes e prontas para uso com PlatformIO.

| Biblioteca | Descrição | Versão |
|:-----------|:----------|:------:|
| 🔌 **[ConectividadeESP32](https://github.com/professorThiago/ConectividadeESP32)** | WiFi + MQTT não-bloqueante, fila offline, AWS IoT Core, PSRAM | `3.0.0` |
| 🪲 **[DebugManager](https://github.com/professorThiago/DebugManager)** | Sistema de log em 6 níveis para ESP32 — sem `Serial.println` espalhado | `3.0.0` |
